# Insurance Policy Management System

University project (DSE & DBD). Monorepo with a React frontend and a planned
FastAPI backend.

## Status

Project foundation only. No business modules are implemented yet.

## Structure

```
.
├── frontend/   React + Vite (JavaScript) SPA — set up and running
└── backend/    FastAPI REST API — placeholder, not implemented
```

## Frontend quick start

```bash
cd frontend
npm install
npm run dev
```

See [frontend/README.md](frontend/README.md) for scripts, folder layout and
architecture rules.

Policy Catalog & Issuance · Premium Schedule & Payments · Claims · Renewals ·
Agent Commission · MIS Reports
